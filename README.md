# Federated Learning with Coordinated Zero-Sum Masking 
[![Framework: Flower](https://shields.io)](https://flower.dev)
[![Library: PyTorch](https://shields.io)](https://pytorch.org)
[![License: MIT](https://shields.io)](LICENSE)

Official Python implementation of the core architectural framework for **"Federated Learning with Coordinated Zero-Sum Perturbations and LLM-Based Training Diagnostics"**.

This repository introduces a mathematically sound, coordinated zero-sum masking infrastructure engineered for decentralized model training ecosystems. Under this layout, client-side perturbation layers generate unique, structured masking matrices that perfectly cancel each other out during server-side global parameter aggregation. This ensures total data obfuscation at the edge without degrading overall convergence behavior.

---

## 🌟 Technical Highlights

• We propose a coordinated zero-sum masking mechanism with structured client-specific noise vectors for federated learning, ensuring unbiased global aggregation while masking individual client updates before server observation.
• We design a noise matrix framework generated by an isolated zero-sum masking
coordinator that enables coordinated perturbation with a Bernoulli-based selective sampling strategy while controlling perturbation sparsity and preserving model utility.
• We incorporate an LLM-based reasoning module at the server side that generates structured, evidence-grounded explanations of client-level and global training behavior after each communication round, improving the transparency and interpretability of the masking-based FL process.
• We demonstrate through experiments on synthetic and NSL-KDD datasets that the proposed approach preserves model performance under the evaluated masking settings, evaluates robustness under client failure scenarios, and provides interpretable diagnostic reasoning throughout training

## 🚀 Installation & Local Testing

### 1. Installation
Clone the repository:
```bash
git clone https://github.com
cd Coordinated_Zero_Sum_Masking_Federated_Learning-
pip install -r requirements.txt
```

### 2. Standard Local Run
To spin up a simulation of coordinated clients interacting with an honest-but-curious centralized cloud topology:
```bash
# Start the central aggregation server
python src/server.py 

# Spin up independent client nodes (In separate terminal windows)
python src/client.py --partition-id 7 --num-partitions 0
python src/client.py ---partition-id 7 --num-partitions 1
python src/client.py --partition-id 7 --num-partitions 2

```
